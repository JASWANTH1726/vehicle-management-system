# Vehicle Management System

[![Deploy to GitHub Pages](https://github.com/JASWANTH1726/vehicle-management-system/actions/workflows/pages.yml/badge.svg)](https://github.com/JASWANTH1726/vehicle-management-system/actions/workflows/pages.yml)

A browser-based app for managing vehicles, maintenance records, and fuel records.

## Live demo

https://jaswanth1726.github.io/vehicle-management-system/

## Features

- Add and manage vehicles, maintenance records, and fuel records
- Filter records by vehicle
- Import and export data as JSON
- Save data in the browser using local storage

Data is stored only in the current browser and device. Use the export feature to back it up or move it to another browser.

## Run locally

Open `index.html` in a browser, or serve this folder with a static HTTP server.

## Deployment

GitHub Actions deploys the site to GitHub Pages whenever changes are pushed to `main`.
